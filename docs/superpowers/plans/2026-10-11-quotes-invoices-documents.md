# Quotes and Invoices as Real Documents (Stage 2, slice A) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A quote or invoice is built from lines (picked from a price list or typed), its VAT and totals are calculated by the database, it gets a generated number and a frozen copy of the client and company details when it goes out, and it can be shown on screen in the HIMARK design.

**Architecture:** The database is the authority. Tables for company settings, a price list, quote and invoice lines and number counters; triggers that calculate totals from lines and hold a draft reference; a guard and a freeze for the signed-in roles; and `send_quote`, `issue_invoice` and `duplicate_quote` functions. Pure TypeScript readers and a pure document-view builder (unit tested) sit between the database and the screens: server actions, a line editor, company and price-list pages, and a document page that prints cleanly.

**Tech Stack:** Next.js 16 App Router (server actions, `useActionState`), React 19, Supabase Postgres 17 (RLS, security definer functions), TypeScript run by `node --test --experimental-strip-types`, Tailwind.

**Spec:** `docs/superpowers/specs/2026-10-10-quotes-invoices-documents-design.md`

## Global Constraints

- `unison-uat` (Supabase project `nwdzpjzllhhqwawmsxjd`) is production. Every test row is deleted, with its audit events. Rolled-back probes before applying any migration. **Only the controller applies migrations and runs `pnpm test:rls`**; an implementer writes the files and never touches a database.
- Migrations are append-only. Decisions are made in the database and tested there; the UI mirrors them.
- A control in the UI is a claim the product supports it. No role-based behaviour is invented.
- No real bank, VAT, phone or address value in code or tests; they live in settings.
- Secrets live in `.env.local` only.
- Never `git add -A`, `git checkout .`, `git restore .`, `git stash`, `git clean`; stage explicit paths. Never touch anything under `public/` or `features/**/record-collection-workspace.tsx`. Commit and push only when the user asks (task commits on the feature branch are part of the plan).
- Next.js 16 has breaking changes: before using an API that differs from older versions, read `node_modules/next/dist/docs/`. A `'use server'` file exports only async functions and types; never call a function exported from a `'use client'` module from a server component; shared modules that unit tests import use relative imports with the `.ts` extension, no `@/` alias, no `server-only`.
- React 19 resets a `<form action>` after the action finishes and when it fails: any field whose value matters afterwards is controlled state or robust to the reset.
- Interactive controls have accessible names; a malformed id returns 404 before any data load.
- Document numbers: `PREFIX-Q-YYYY-NNNNN` for quotes and `PREFIX-I-YYYY-NNNNN` for invoices, a separate counter per organisation, kind and year, restarting each January (year in `Africa/Johannesburg`).
- VAT is **Standard** (rate from the settings, 15.00 by default) or **Zero-rated**, per line; the rate is copied onto a document when it is created and never changes after.
- A document is **locked once sent or issued**: a quote is "sent or beyond" in `Sent`, `Accepted`, `Declined`, `Expired`; an invoice is "issued or beyond" in every status except `Draft`. After that only status and notes can change (a quote's status among Sent, Accepted, Declined, Expired; an invoice's among Issued, Partially Paid, Paid, Overdue, Cancelled, by hand until payments arrive in slice C).

## Spec amendments made while planning

These are small, deliberate departures from the spec text; the spec file is updated to match in Task 9. Each is a **Ruling**.

1. **Draft reference instead of a nullable number.** The number column stays `NOT NULL`; a draft carries `DRAFT-` plus eight hex characters, generated by the trigger, and the real number replaces it at send or issue. Why: the dashboard activity feed, the global search index, the registers, option lists and the timeline all read the number as a non-null label. Cost if wrong: a register row shows `DRAFT-1a2b3c4d`; the document page shows no number for a draft.
2. **No `unique (parent, position)`.** Lines are ordered by `position` then `created_at`; "move up/down" swaps two positions. Why: a uniqueness rule makes the swap fail halfway.
3. **No TypeScript totals mirror.** Totals are never calculated in TypeScript; the editor and the document show the stored values. The spec's "totals mirror" unit test is dropped; the database test covers the arithmetic.
4. **Guard and freeze apply to `authenticated` and `anon`.** The service role (fixtures) and the definer functions are not held to them, exactly like `leads_guard_conversion`. Totals are calculated for everyone.
5. **Two extra settings:** `tagline` (the design prints it) and `quote_closing_text` / `invoice_closing_text` (the design's "Next steps" and "Thank you" copy, so no wording is in code).
6. **A quote or invoice needs a client record** (`client_id`), not only a typed prospect name, so the snapshot has an address and VAT number. The error says to convert the lead first.
7. **A permission `company.manage`** (owner and admin) in the roles registry gates the company details UI; the database rule is `has_role(owner, admin)`.
8. **The logo is the wordmark** (`/brand/himark-wordmark.png`); the dark H mark is not in `public/brand` as a standalone file, so the design's mark-plus-wordmark lockup is a follow-up needing that file.

## Review Focus

The inputs the spec implies that no single task's tests would otherwise exercise, most likely first. Each has a test in the task that owns the code.

1. **Rounding.** Half-cent cases must round the way the design's sums do (1.5 x 0.15 = 0.23; VAT 30.045 = 30.05). Task 1 database test.
2. **Two people sending at once.** Distinct numbers for different drafts; exactly one winner for the same draft; no gap after a refused send. Task 2.
3. **A stale form after the document went out.** Editing, adding or removing a line of a sent document, or saving an old edit form, shows the "already sent" message, not a raw error. Task 2 (database), Task 3 (message mapping), Task 5 (save action).
4. **Hostile and very long text on a printed document** (a title with markup, a 3,000-character description, a client name that is a whole sentence). Rendered as text, wrapping, never overflowing the page. Task 3 (view builder), Task 8 (sheet) and the preview check.
5. **A client with no address or VAT number, and a company with no bank details.** The document shows only what exists, with no "null" or empty labels. Task 3.
6. **A zero-rated-only document** shows VAT 0.00, not a missing row. Task 3.
7. **Company details missing at send time** gives a message that says where to fix it. Task 2 and Task 3.

-- ---------------------------------------------------------------------------
-- 7. Before every write: a draft reference when there is no number, the VAT rate
--    copied from the settings on insert and never changed after, and the totals
--    calculated from the lines whoever writes them. An invoice that is still a draft
--    has its balance follow its total.
-- ---------------------------------------------------------------------------
create or replace function public.quotes_documents_before() returns trigger
language plpgsql security invoker set search_path = '' as $$
declare
  v_sub numeric(14,2);
  v_std numeric(14,2);
  v_rate numeric(5,2);
begin
  if tg_op = 'INSERT' then
    if new.quote_number is null or btrim(new.quote_number) = '' then
      new.quote_number := 'DRAFT-' || substr(replace(gen_random_uuid()::text, '-', ''), 1, 8);
    end if;
    select s.vat_rate into v_rate from public.organization_settings s where s.organization_id = new.organization_id;
    if found then
      new.vat_rate := v_rate;
    end if;
    new.subtotal := 0;
    new.tax_amount := 0;
    new.total_amount := 0;
  else
    new.vat_rate := old.vat_rate;
    select coalesce(sum(l.line_amount), 0), coalesce(sum(l.line_amount) filter (where l.vat_code = 'standard'), 0)
      into v_sub, v_std
      from public.quote_lines l
      where l.quote_id = new.id and l.organization_id = new.organization_id;
    new.subtotal := v_sub;
    new.tax_amount := round(v_std * new.vat_rate / 100, 2);
    new.total_amount := v_sub + new.tax_amount;
  end if;
  return new;
end $$;

create or replace function public.invoices_documents_before() returns trigger
language plpgsql security invoker set search_path = '' as $$
declare
  v_sub numeric(14,2);
  v_std numeric(14,2);
  v_rate numeric(5,2);
begin
  if tg_op = 'INSERT' then
    if new.invoice_number is null or btrim(new.invoice_number) = '' then
      new.invoice_number := 'DRAFT-' || substr(replace(gen_random_uuid()::text, '-', ''), 1, 8);
    end if;
    select s.vat_rate into v_rate from public.organization_settings s where s.organization_id = new.organization_id;
    if found then
      new.vat_rate := v_rate;
    end if;
    new.subtotal := 0;
    new.tax_amount := 0;
    new.total_amount := 0;
  else
    new.vat_rate := old.vat_rate;
    select coalesce(sum(l.line_amount), 0), coalesce(sum(l.line_amount) filter (where l.vat_code = 'standard'), 0)
      into v_sub, v_std
      from public.invoice_lines l
      where l.invoice_id = new.id and l.organization_id = new.organization_id;
    new.subtotal := v_sub;
    new.tax_amount := round(v_std * new.vat_rate / 100, 2);
    new.total_amount := v_sub + new.tax_amount;
  end if;
  if new.status = 'Draft' then
    new.balance_amount := new.total_amount;
  end if;
  return new;
end $$;

create trigger quotes_documents_before
  before insert or update on public.quotes
  for each row execute function public.quotes_documents_before();
create trigger invoices_documents_before
  before insert or update on public.invoices
  for each row execute function public.invoices_documents_before();

-- A line changing touches its document, which makes the trigger above recalculate it.
create or replace function public.touch_quote_for_line() returns trigger
language plpgsql security invoker set search_path = '' as $$
begin
  if tg_op in ('INSERT', 'UPDATE') then
    update public.quotes set updated_at = now() where id = new.quote_id and organization_id = new.organization_id;
  end if;
  if tg_op = 'DELETE' or (tg_op = 'UPDATE' and old.quote_id is distinct from new.quote_id) then
    update public.quotes set updated_at = now() where id = old.quote_id and organization_id = old.organization_id;
  end if;
  return null;
end $$;

create or replace function public.touch_invoice_for_line() returns trigger
language plpgsql security invoker set search_path = '' as $$
begin
  if tg_op in ('INSERT', 'UPDATE') then
    update public.invoices set updated_at = now() where id = new.invoice_id and organization_id = new.organization_id;
  end if;
  if tg_op = 'DELETE' or (tg_op = 'UPDATE' and old.invoice_id is distinct from new.invoice_id) then
    update public.invoices set updated_at = now() where id = old.invoice_id and organization_id = old.organization_id;
  end if;
  return null;
end $$;

create trigger quote_lines_touch_quote
  after insert or update or delete on public.quote_lines
  for each row execute function public.touch_quote_for_line();
create trigger invoice_lines_touch_invoice
  after insert or update or delete on public.invoice_lines
  for each row execute function public.touch_invoice_for_line();

```sql
-- Stage 2, slice A, part 2: numbering, send and issue, and the rules that stop a sent
-- document being changed.
--
-- The guard and freeze rules apply to the signed-in roles (authenticated and anon), the
-- same way leads_guard_conversion does: the definer functions below and referential
-- actions run as the table owner and are not held to them, and neither is the service
-- role used by fixtures. Totals are calculated for everyone.

-- ---------------------------------------------------------------------------
-- 1. The next number: PREFIX-Q-YYYY-NNNNN or PREFIX-I-YYYY-NNNNN, one counter per
--    organisation, kind and year (the year in South Africa). The row lock taken by the
--    upsert serialises two callers; the increment rolls back with the caller's
--    transaction, so a failed send leaves no gap.
-- ---------------------------------------------------------------------------
create or replace function public.next_document_number(p_org uuid, p_kind text) returns text
language plpgsql security definer set search_path = '' as $$
declare
  v_prefix text;
  v_year integer := extract(year from (now() at time zone 'Africa/Johannesburg'))::integer;
  v_next integer;
begin
  if p_kind not in ('quote', 'invoice') then
    raise exception 'DOCUMENT_KIND_UNKNOWN' using errcode = '22023';
  end if;
  select s.document_prefix into v_prefix from public.organization_settings s where s.organization_id = p_org;
  if v_prefix is null then
    raise exception 'COMPANY_DETAILS_MISSING' using errcode = '23514';
  end if;
  insert into public.document_counters as c (organization_id, kind, year, last_number)
  values (p_org, p_kind, v_year, 1)
  on conflict (organization_id, kind, year) do update set last_number = c.last_number + 1
  returning c.last_number into v_next;
  return v_prefix || '-' || case p_kind when 'quote' then 'Q' else 'I' end || '-' || v_year::text || '-' || lpad(v_next::text, 5, '0');
end $$;

revoke all on function public.next_document_number(uuid, text) from public, anon, authenticated;

-- ---------------------------------------------------------------------------
-- 2. The guard and the freeze, on the documents themselves. These replace the part 1
--    functions of the same name and keep everything they did.
-- ---------------------------------------------------------------------------
create or replace function public.quotes_documents_before() returns trigger
language plpgsql security invoker set search_path = '' as $$
declare
  v_member boolean := current_user in ('authenticated', 'anon');
  v_new_draft boolean := new.status in ('Draft', 'Internal Review');
  v_old_draft boolean;
  v_sub numeric(14,2);
  v_std numeric(14,2);
  v_rate numeric(5,2);
begin
  if tg_op = 'INSERT' then
    if v_member then
      if not v_new_draft then
        raise exception 'QUOTE_USE_SEND' using errcode = '23514';
      end if;
      if new.quote_number is not null and btrim(new.quote_number) <> '' then
        raise exception 'DOCUMENT_NUMBER_GENERATED' using errcode = '23514';
      end if;
      new.bill_to := null;
      new.issuer := null;
    end if;
    if new.quote_number is null or btrim(new.quote_number) = '' then
      new.quote_number := 'DRAFT-' || substr(replace(gen_random_uuid()::text, '-', ''), 1, 8);
    end if;
    select s.vat_rate into v_rate from public.organization_settings s where s.organization_id = new.organization_id;
    if found then
      new.vat_rate := v_rate;
    end if;
    new.subtotal := 0;
    new.tax_amount := 0;
    new.total_amount := 0;
  else
    v_old_draft := old.status in ('Draft', 'Internal Review');
    if v_member then
      if new.quote_number is distinct from old.quote_number then
        raise exception 'DOCUMENT_NUMBER_GENERATED' using errcode = '23514';
      end if;
      if new.bill_to is distinct from old.bill_to or new.issuer is distinct from old.issuer then
        raise exception 'DOCUMENT_SNAPSHOT_GENERATED' using errcode = '23514';
      end if;
      if v_old_draft and not v_new_draft then
        raise exception 'QUOTE_USE_SEND' using errcode = '23514';
      end if;
      if not v_old_draft and v_new_draft then
        raise exception 'QUOTE_CANNOT_REOPEN' using errcode = '23514';
      end if;
      if not v_old_draft and (
        new.client_id is distinct from old.client_id
        or new.client_name is distinct from old.client_name
        or new.issue_date is distinct from old.issue_date
        or new.valid_until is distinct from old.valid_until
        or new.currency is distinct from old.currency
        or new.terms is distinct from old.terms
        or new.project_name is distinct from old.project_name
        or new.project_description is distinct from old.project_description
        or new.project_ref is distinct from old.project_ref
        or new.client_ref is distinct from old.client_ref
      ) then
        raise exception 'QUOTE_FROZEN' using errcode = '23514';
      end if;
    end if;
    new.vat_rate := old.vat_rate;
    select coalesce(sum(l.line_amount), 0), coalesce(sum(l.line_amount) filter (where l.vat_code = 'standard'), 0)
      into v_sub, v_std
      from public.quote_lines l
      where l.quote_id = new.id and l.organization_id = new.organization_id;
    new.subtotal := v_sub;
    new.tax_amount := round(v_std * new.vat_rate / 100, 2);
    new.total_amount := v_sub + new.tax_amount;
  end if;
  return new;
end $$;

      new.invoice_number := 'DRAFT-' || substr(replace(gen_random_uuid()::text, '-', ''), 1, 8);

    select s.vat_rate into v_rate from public.organization_settings s where s.organization_id = new.organization_id;
    if found then
      new.vat_rate := v_rate;
    end if;
    new.subtotal := 0;
    new.tax_amount := 0;
    new.total_amount := 0;
  else
    v_old_draft := old.status = 'Draft';
    if v_member then
      if new.invoice_number is distinct from old.invoice_number then
        raise exception 'DOCUMENT_NUMBER_GENERATED' using errcode = '23514';
      end if;
      if new.bill_to is distinct from old.bill_to or new.issuer is distinct from old.issuer then
        raise exception 'DOCUMENT_SNAPSHOT_GENERATED' using errcode = '23514';
      end if;
      if v_old_draft and not v_new_draft then
        raise exception 'INVOICE_USE_ISSUE' using errcode = '23514';
      end if;
      if not v_old_draft and v_new_draft then
        raise exception 'INVOICE_CANNOT_REOPEN' using errcode = '23514';
      end if;
      if not v_old_draft and (
        new.client_id is distinct from old.client_id
        or new.client_name is distinct from old.client_name
        or new.issue_date is distinct from old.issue_date
        or new.due_date is distinct from old.due_date
        or new.currency is distinct from old.currency
        or new.payment_terms is distinct from old.payment_terms
        or new.project_name is distinct from old.project_name
        or new.project_description is distinct from old.project_description
        or new.project_ref is distinct from old.project_ref
        or new.client_ref is distinct from old.client_ref
      ) then
        raise exception 'INVOICE_FROZEN' using errcode = '23514';
      end if;
    end if;
    new.vat_rate := old.vat_rate;
    select coalesce(sum(l.line_amount), 0), coalesce(sum(l.line_amount) filter (where l.vat_code = 'standard'), 0)
      into v_sub, v_std
      from public.invoice_lines l
      where l.invoice_id = new.id and l.organization_id = new.organization_id;
    new.subtotal := v_sub;
    new.tax_amount := round(v_std * new.vat_rate / 100, 2);
    new.total_amount := v_sub + new.tax_amount;
  end if;
  if new.status = 'Draft' then
    new.balance_amount := new.total_amount;
  end if;
  return new;
end $$;

-- ---------------------------------------------------------------------------
-- 3. The freeze, on the lines: a signed-in role cannot add, change or remove a line of a
--    document that has gone out.
-- ---------------------------------------------------------------------------
create or replace function public.quote_lines_freeze() returns trigger
language plpgsql security invoker set search_path = '' as $$
declare
  v_status text;
begin
  if current_user not in ('authenticated', 'anon') then
    return coalesce(new, old);
  end if;
  if tg_op in ('UPDATE', 'DELETE') then
    select q.status into v_status from public.quotes q where q.id = old.quote_id and q.organization_id = old.organization_id;
    if found and v_status not in ('Draft', 'Internal Review') then
      raise exception 'QUOTE_FROZEN' using errcode = '23514';
    end if;
  end if;
  if tg_op in ('INSERT', 'UPDATE') then
    select q.status into v_status from public.quotes q where q.id = new.quote_id and q.organization_id = new.organization_id;
    if found and v_status not in ('Draft', 'Internal Review') then
      raise exception 'QUOTE_FROZEN' using errcode = '23514';
    end if;
  end if;
  return coalesce(new, old);
end $$;

create or replace function public.invoice_lines_freeze() returns trigger
language plpgsql security invoker set search_path = '' as $$
declare
  v_status text;
begin
  if current_user not in ('authenticated', 'anon') then
    return coalesce(new, old);
  end if;
  if tg_op in ('UPDATE', 'DELETE') then
    select i.status into v_status from public.invoices i where i.id = old.invoice_id and i.organization_id = old.organization_id;
    if found and v_status <> 'Draft' then

  if tg_op in ('INSERT', 'UPDATE') then

-- ---------------------------------------------------------------------------
-- 4. Send a quote. security definer, because it writes the number and the snapshots that
--    members may not write. It therefore does its own checks: the caller must be a member
--    of the quote's organisation, and everything it reads or writes is scoped to it.
-- ---------------------------------------------------------------------------
create or replace function public.send_quote(p_id uuid) returns jsonb
language plpgsql security definer set search_path = '' as $$
declare
  v_org uuid;
  v_quote public.quotes%rowtype;
  v_settings public.organization_settings%rowtype;
  v_client public.clients%rowtype;
  v_number text;
  v_issue date;
  v_valid date;
begin
  select q.organization_id into v_org from public.quotes q where q.id = p_id;
  if not found or not public.is_member_of(v_org) then
    raise exception 'QUOTE_NOT_FOUND' using errcode = '42501';
  end if;
  -- The row lock serialises two simultaneous sends of the same quote.
  select * into v_quote from public.quotes where id = p_id for update;
  if not found then
    raise exception 'QUOTE_NOT_FOUND' using errcode = '42501';
  end if;
  if v_quote.archived_at is not null or v_quote.status not in ('Draft', 'Internal Review') then
    raise exception 'QUOTE_NOT_DRAFT' using errcode = '23514';
  end if;
  select * into v_client from public.clients where id = v_quote.client_id and organization_id = v_org;
  if v_quote.client_id is null or not found then
    raise exception 'QUOTE_NEEDS_CLIENT' using errcode = '23514';
  end if;
  if not exists (select 1 from public.quote_lines l where l.quote_id = p_id and l.organization_id = v_org) then
    raise exception 'QUOTE_NEEDS_LINES' using errcode = '23514';
  end if;
  select * into v_settings from public.organization_settings where organization_id = v_org;
  if not found or v_settings.document_prefix is null or btrim(coalesce(v_settings.legal_name, '')) = '' then
    raise exception 'COMPANY_DETAILS_MISSING' using errcode = '23514';
  end if;

  v_issue := (now() at time zone 'Africa/Johannesburg')::date;
  v_valid := coalesce(v_quote.valid_until, v_issue + v_settings.default_quote_valid_days);
  if v_valid < v_issue then
    raise exception 'QUOTE_VALID_BEFORE_ISSUE' using errcode = '23514';
  end if;
  v_number := public.next_document_number(v_org, 'quote');

  update public.quotes set
    quote_number = v_number,
    status = 'Sent',
    issue_date = v_issue,
    valid_until = v_valid,
    terms = coalesce(nullif(btrim(v_quote.terms), ''), v_settings.default_quote_terms),
    client_name = v_client.name,
    bill_to = jsonb_build_object(
      'name', v_client.name, 'address_line1', v_client.address_line1, 'address_line2', v_client.address_line2,
      'city', v_client.city, 'postal_code', v_client.postal_code, 'country', v_client.country,
      'vat_number', v_client.vat_number),
    issuer = to_jsonb(v_settings) - 'id' - 'organization_id' - 'created_at' - 'updated_at'
  where id = p_id;

  return jsonb_build_object('id', p_id, 'number', v_number);
end $$;

-- ---------------------------------------------------------------------------
-- 5. Issue an invoice, the same way.
-- ---------------------------------------------------------------------------
create or replace function public.issue_invoice(p_id uuid) returns jsonb
language plpgsql security definer set search_path = '' as $$
declare
  v_org uuid;
  v_invoice public.invoices%rowtype;
  v_settings public.organization_settings%rowtype;
  v_client public.clients%rowtype;
  v_number text;
  v_issue date;
  v_due date;
begin
  select i.organization_id into v_org from public.invoices i where i.id = p_id;
  if not found or not public.is_member_of(v_org) then
    raise exception 'INVOICE_NOT_FOUND' using errcode = '42501';
  end if;
  select * into v_invoice from public.invoices where id = p_id for update;
  if not found then
    raise exception 'INVOICE_NOT_FOUND' using errcode = '42501';
  end if;
  if v_invoice.archived_at is not null or v_invoice.status <> 'Draft' then
    raise exception 'INVOICE_NOT_DRAFT' using errcode = '23514';
  end if;
  select * into v_client from public.clients where id = v_invoice.client_id and organization_id = v_org;
  if v_invoice.client_id is null or not found then
    raise exception 'INVOICE_NEEDS_CLIENT' using errcode = '23514';
  end if;
  if not exists (select 1 from public.invoice_lines l where l.invoice_id = p_id and l.organization_id = v_org) then
    raise exception 'INVOICE_NEEDS_LINES' using errcode = '23514';
  end if;
  select * into v_settings from public.organization_settings where organization_id = v_org;
  if not found or v_settings.document_prefix is null or btrim(coalesce(v_settings.legal_name, '')) = '' then
    raise exception 'COMPANY_DETAILS_MISSING' using errcode = '23514';
  end if;

  v_issue := coalesce(v_invoice.issue_date, (now() at time zone 'Africa/Johannesburg')::date);
  v_due := coalesce(v_invoice.due_date, v_issue + v_settings.default_payment_days);
  if v_due < v_issue then
    raise exception 'INVOICE_DUE_BEFORE_ISSUE' using errcode = '23514';
  end if;
  v_number := public.next_document_number(v_org, 'invoice');

  update public.invoices set
    invoice_number = v_number,
    status = 'Issued',
    issue_date = v_issue,
    due_date = v_due,
    payment_terms = coalesce(nullif(btrim(v_invoice.payment_terms), ''), v_settings.default_payment_terms),
    client_name = v_client.name,
    bill_to = jsonb_build_object(
      'name', v_client.name, 'address_line1', v_client.address_line1, 'address_line2', v_client.address_line2,
      'city', v_client.city, 'postal_code', v_client.postal_code, 'country', v_client.country,
      'vat_number', v_client.vat_number),
    issuer = to_jsonb(v_settings) - 'id' - 'organization_id' - 'created_at' - 'updated_at',
    balance_amount = v_invoice.total_amount
  where id = p_id;

  return jsonb_build_object('id', p_id, 'number', v_number);
end $$;

-- ---------------------------------------------------------------------------
-- 6. Duplicate a quote as a new draft, with its lines and project details. security
--    invoker: row level security already limits the caller to their own organisations,
--    and what is created is only what a member could create by hand.
-- ---------------------------------------------------------------------------
create or replace function public.duplicate_quote(p_id uuid) returns uuid
language plpgsql security invoker set search_path = '' as $$
declare
  v_src public.quotes%rowtype;
  v_new uuid;
begin
  select * into v_src from public.quotes where id = p_id;
  if not found then
    raise exception 'QUOTE_NOT_FOUND' using errcode = '42501';
  end if;
  insert into public.quotes (
    organization_id, client_id, client_name, contact_name, lead_id, opportunity_id, owner_id, currency, status,
    terms, notes, project_name, project_description, project_ref, client_ref)
  values (
    v_src.organization_id, v_src.client_id, v_src.client_name, v_src.contact_name, v_src.lead_id, v_src.opportunity_id,
    v_src.owner_id, v_src.currency, 'Draft', v_src.terms, v_src.notes, v_src.project_name, v_src.project_description,
    v_src.project_ref, v_src.client_ref)
  returning id into v_new;
  insert into public.quote_lines (organization_id, quote_id, position, title, description, quantity, unit_price, vat_code, price_list_item_id)
  select l.organization_id, v_new, l.position, l.title, l.description, l.quantity, l.unit_price, l.vat_code, l.price_list_item_id
  from public.quote_lines l
  where l.quote_id = p_id and l.organization_id = v_src.organization_id;
  return v_new;
end $$;

revoke all on function public.send_quote(uuid) from public, anon;
revoke all on function public.issue_invoice(uuid) from public, anon;
revoke all on function public.duplicate_quote(uuid) from public, anon;
grant execute on function public.send_quote(uuid) to authenticated;
grant execute on function public.issue_invoice(uuid) to authenticated;
grant execute on function public.duplicate_quote(uuid) to authenticated;
```

// Shared by server and client code and by unit tests: no directive, no imports.

export const VAT_CODES = ['standard', 'zero'] as const
export type VatCode = (typeof VAT_CODES)[number]
export const VAT_LABELS: Record<VatCode, string> = { standard: 'Standard rate', zero: 'Zero-rated' }

export type DocumentKind = 'quote' | 'invoice'

export const DOCUMENTS = {
  quote: { table: 'quotes', lines: 'quote_lines', parentColumn: 'quote_id', numberColumn: 'quote_number', base: '/commercial/quotes', label: 'quote', title: 'QUOTE' },
  invoice: { table: 'invoices', lines: 'invoice_lines', parentColumn: 'invoice_id', numberColumn: 'invoice_number', base: '/finance/invoices', label: 'invoice', title: 'INVOICE' },
} as const

export function isDocumentKind(value: unknown): value is DocumentKind {
  return typeof value === 'string' && Object.hasOwn(DOCUMENTS, value)
}

/** A quote can be edited freely in these statuses; once it is sent it is in one of the next. */
export const QUOTE_DRAFT_STATUSES = ['Draft', 'Internal Review'] as const
export const QUOTE_SENT_STATUSES = ['Sent', 'Accepted', 'Declined', 'Expired'] as const
export const INVOICE_DRAFT_STATUSES = ['Draft'] as const
export const INVOICE_ISSUED_STATUSES = ['Issued', 'Partially Paid', 'Paid', 'Overdue', 'Cancelled'] as const

export function isDraftStatus(kind: DocumentKind, status: unknown): boolean {
  const drafts: readonly string[] = kind === 'quote' ? QUOTE_DRAFT_STATUSES : INVOICE_DRAFT_STATUSES
  return typeof status === 'string' && drafts.includes(status)
}

/** A draft carries "DRAFT-" and eight hex characters in its number column until it goes out. */
export const isDraftReference = (number: unknown): boolean => typeof number === 'string' && number.startsWith('DRAFT-')

// Pure readers for the document forms, so the validation the server actions depend on is unit
// testable. Relative imports only: Node's test runner cannot resolve '@/', and 'use server'
// modules cannot be imported by a test.
import { isUuid } from '../../lib/utils/index.ts'
import { VAT_CODES, type VatCode } from './vocabulary.ts'

const value = (form: FormData, key: string) => String(form.get(key) ?? '').trim()
const optional = (form: FormData, key: string) => value(form, key) || null
const isOneOf = (options: readonly string[], candidate: string) => options.includes(candidate)

const BRAND_PATH = /^\/brand\/[A-Za-z0-9_-][A-Za-z0-9._-]*$/
const PREFIX = /^[A-Z0-9]{2,8}$/

/** "1500", "99.50", "1 200,5" -> a number and how many decimals were typed; null when it is not a plain non-negative decimal. */
export function parseDecimal(raw: string): { value: number; decimals: number } | null {
  const cleaned = raw.replace(/[\s ]/g, '').replace(',', '.')
  if (!/^\d{1,12}(\.\d+)?$/.test(cleaned)) return null
  return { value: Number(cleaned), decimals: cleaned.includes('.') ? cleaned.split('.')[1].length : 0 }
}

type Failure = { error: string }

function readMoney(form: FormData, key: string, label: string): number | Failure {
  const parsed = parseDecimal(value(form, key))
  if (!parsed) return { error: `Enter a ${label}, for example 1500 or 99.50.` }
  if (parsed.decimals > 2) return { error: `The ${label} can have at most 2 decimals.` }
  if (parsed.value > 9999999.99) return { error: `The ${label} is too large.` }
  return parsed.value
}

function readVatCode(form: FormData): VatCode | Failure {
  const code = value(form, 'vatCode')
  return isOneOf(VAT_CODES, code) ? (code as VatCode) : { error: 'Choose Standard rate or Zero-rated VAT.' }
}

export type LineFields = {
  title: string
  description: string | null
  quantity: number
  unit_price: number
  vat_code: VatCode
  price_list_item_id: string | null
}

export function readLineFields(form: FormData): LineFields | Failure {
  const title = value(form, 'title')
  if (!title) return { error: 'A title is required.' }
  if (title.length > 200) return { error: 'The title is too long (200 characters at most).' }
  const description = optional(form, 'description')
  if (description && description.length > 2000) return { error: 'The description is too long (2,000 characters at most).' }

  const quantity = parseDecimal(value(form, 'quantity'))
  if (!quantity) return { error: 'Enter a quantity, for example 1 or 2.5.' }
  if (quantity.decimals > 3) return { error: 'The quantity can have at most 3 decimals.' }
  if (quantity.value <= 0) return { error: 'Quantity must be more than zero.' }
  if (quantity.value > 99999.999) return { error: 'The quantity is too large.' }

  const price = readMoney(form, 'unitPrice', 'unit price')
  if (typeof price !== 'number') return price
  const vat = readVatCode(form)
  if (typeof vat !== 'string') return vat
  const itemId = optional(form, 'priceListItemId')
  if (itemId && !isUuid(itemId)) return { error: 'That price list item is not valid.' }
  return { title, description, quantity: quantity.value, unit_price: price, vat_code: vat, price_list_item_id: itemId }
}

export type PriceItemFields = { title: string; description: string | null; unit_price: number; vat_code: VatCode }

export function readPriceItemFields(form: FormData): PriceItemFields | Failure {
  const title = value(form, 'title')
  if (!title) return { error: 'A title is required.' }
  if (title.length > 200) return { error: 'The title is too long (200 characters at most).' }
  const description = optional(form, 'description')
  if (description && description.length > 2000) return { error: 'The description is too long (2,000 characters at most).' }
  const price = readMoney(form, 'unitPrice', 'unit price')
  if (typeof price !== 'number') return price
  const vat = readVatCode(form)
  if (typeof vat !== 'string') return vat
  return { title, description, unit_price: price, vat_code: vat }
}

function readInteger(form: FormData, key: string, min: number, max: number, message: string): number | Failure {
  const raw = value(form, key)
  if (!/^\d{1,4}$/.test(raw)) return { error: message }
  const parsed = Number(raw)
  return parsed < min || parsed > max ? { error: message } : parsed
}

export function readCompanyFields(form: FormData): CompanyFields | Failure {
  const legalName = value(form, 'legalName')
  if (!legalName) return { error: 'The company name is required.' }
  if (legalName.length > 200) return { error: 'The company name is too long (200 characters at most).' }
  const prefix = value(form, 'documentPrefix').toUpperCase()
  if (!PREFIX.test(prefix) || prefix === 'DRAFT') return { error: 'Use 2 to 8 letters or numbers for the document prefix (not DRAFT).' }
  const rate = parseDecimal(value(form, 'vatRate'))
  if (!rate || rate.decimals > 2 || rate.value > 100) return { error: 'Enter the VAT rate as a percentage between 0 and 100, for example 15.' }
  const validDays = readInteger(form, 'defaultQuoteValidDays', 1, 365, 'A quote must be valid for between 1 and 365 days.')
  if (typeof validDays !== 'number') return validDays
  const paymentDays = readInteger(form, 'defaultPaymentDays', 0, 365, 'Payment days must be between 0 and 365.')
  if (typeof paymentDays !== 'number') return paymentDays
  const email = optional(form, 'email')
  if (email && !/^\S+@\S+\.\S+$/.test(email)) return { error: 'Enter a valid company email.' }
  if (email && email.length > 200) return { error: 'The company email is too long.' }
  const logo = optional(form, 'logoPath')
  const header = optional(form, 'headerImagePath')
  for (const path of [logo, header]) {
    if (path && !BRAND_PATH.test(path)) return { error: 'Image paths must be a file in /brand, for example /brand/banner.png.' }
  }

  const result: Record<string, unknown> = {
    legal_name: legalName, email, document_prefix: prefix, vat_rate: rate.value,
    default_quote_valid_days: validDays, default_payment_days: paymentDays, logo_path: logo, header_image_path: header,
  }
  for (const spec of TEXT_FIELDS) {
    const text = optional(form, spec.key)
    if (text && text.length > spec.max) return { error: `${spec.label} is too long (${spec.max.toLocaleString('en-ZA')} characters at most).` }
    result[spec.column] = text
  }
  return result as CompanyFields
}

export type DocumentExtras = {
  project_name: string | null
  project_description: string | null
  project_ref: string | null
  client_ref: string | null
}

export function readDocumentExtras(form: FormData): DocumentExtras | Failure {
  const limits: Array<[key: string, column: keyof DocumentExtras, label: string, max: number]> = [
    ['projectName', 'project_name', 'The project name', 200],
    ['projectDescription', 'project_description', 'The project description', 2000],
    ['projectRef', 'project_ref', 'The project reference', 100],
    ['clientRef', 'client_ref', 'The client reference', 100],
  ]
  const result: DocumentExtras = { project_name: null, project_description: null, project_ref: null, client_ref: null }
  for (const [key, column, label, max] of limits) {
    const text = optional(form, key)
    if (text && text.length > max) return { error: `${label} is too long (${max.toLocaleString('en-ZA')} characters at most).` }
    result[column] = text
  }
  return result
}

// Turns database rows into the document the sheet prints. Pure: the sheet component only lays it out.
// A draft is built from the live client and company details; a document that has gone out is built only
// from the copies frozen onto it, so what the client received can never change.
import { DOCUMENTS, isDraftReference, isDraftStatus, type DocumentKind } from './vocabulary.ts'

type Row = Record<string, unknown>

const text = (raw: unknown): string | null => {
  if (raw === null || raw === undefined) return null
  const trimmed = String(raw).trim()
  return trimmed === '' ? null : trimmed
}

const BRAND_PATH = /^\/brand\/[A-Za-z0-9_-][A-Za-z0-9._-]*$/
const brandPath = (raw: unknown): string | null => {
  const path = text(raw)
  return path && BRAND_PATH.test(path) ? path : null
}

const AMOUNT = new Intl.NumberFormat('en-GB', { minimumFractionDigits: 2, maximumFractionDigits: 2 })
const QUANTITY = new Intl.NumberFormat('en-GB', { maximumFractionDigits: 3 })
const DATE = new Intl.DateTimeFormat('en-GB', { day: 'numeric', month: 'long', year: 'numeric', timeZone: 'UTC' })

export function formatAmount(raw: unknown): string {
  const number = Number(raw)
  return AMOUNT.format(Number.isFinite(number) ? number : 0)
}

export function formatQuantity(raw: unknown): string {
  const number = Number(raw)
  return QUANTITY.format(Number.isFinite(number) ? number : 0)
}

/** "2026-10-07" -> "7 October 2026"; null for blank; the raw text for something that is not a date. */
export function formatDocumentDate(raw: unknown): string | null {
  const value = text(raw)
  if (!value) return null
  const date = new Date(`${value}T00:00:00Z`)
  return Number.isNaN(date.getTime()) ? value : DATE.format(date)
}

function addressLines(source: Row): string[] {
  const cityLine = [text(source.city), text(source.postal_code)].filter(Boolean).join(', ')
  return [text(source.address_line1), text(source.address_line2), cityLine || null, text(source.country)].filter((line): line is string => Boolean(line))
}

/** One item per non-blank line, with any "1." or "2)" typed at the start removed, so the sheet numbers them itself. */
function termItems(raw: unknown): string[] {
  const source = text(raw)
  if (!source) return []
  return source
    .split(/\r?\n/)
    .map((line) => line.replace(/^\s*\d+[.)]\s*/, '').trim())
    .filter(Boolean)
}

  kind: DocumentKind
  title: 'QUOTE' | 'INVOICE'
  draft: boolean
  number: string | null
  issuerMissing: boolean
  headerImage: string | null
  logo: string | null
  tagline: string | null

  billToHeading: string
  billTo: string[]
  project: { title: string | null; lines: string[] } | null
  fromHeading: string
  from: { name: string | null; lines: string[]; vatNumber: string | null }
  currency: string
  lines: Array<{ title: string; description: string | null; quantity: string; unitPrice: string; amount: string }>
  totals: { subtotal: string; vatLabel: string; vat: string; total: string }
  termsHeading: string
  terms: string[]
  termsNumbered: boolean
  bank: Array<{ label: string; value: string }>
  closing: { heading: string; paragraphs: string[] } | null
  footer: { email: string | null; phone: string | null; website: string | null }
}

export function buildDocumentView(input: { kind: DocumentKind; record: Row; lines: Row[]; client: Row | null; settings: Row | null }): DocumentView {
  const { kind, record } = input
  const draft = isDraftStatus(kind, record.status)
  const quote = kind === 'quote'
  const info = DOCUMENTS[kind]

  const issuer: Row = draft ? (input.settings ?? {}) : ((record.issuer as Row | null) ?? {})
  const billSource: Row = draft
    ? (input.client ?? { name: record.client_name })
    : ((record.bill_to as Row | null) ?? { name: record.client_name })

  const rawNumber = text(record[info.numberColumn])
  const number = rawNumber && !isDraftReference(rawNumber) ? rawNumber : null
  const currency = text(record.currency) ?? 'ZAR'
  const clientRef = text(record.client_ref)
  const issueDate = formatDocumentDate(record.issue_date) ?? '—'
  const secondDate = formatDocumentDate(quote ? record.valid_until : record.due_date) ?? '—'

  const details = [
    { label: quote ? 'Quote no.' : 'Invoice no.', value: number ?? 'Draft' },
    { label: 'Issue date', value: issueDate },
    { label: quote ? 'Valid until' : 'Due date', value: secondDate },
    { label: 'Currency', value: currency },
    ...(clientRef ? [{ label: 'Client ref', value: clientRef }] : []),
  ]

  const projectTitle = text(record.project_name)
  const projectLines = [text(record.project_description), text(record.project_ref) ? `Project Ref: ${text(record.project_ref)}` : null].filter((line): line is string => Boolean(line))
  const project = projectTitle || projectLines.length ? { title: projectTitle, lines: projectLines } : null

  const rate = Number(record.vat_rate ?? 15)
  const vatLabel = `VAT (${Number((Number.isFinite(rate) ? rate : 15).toFixed(2))}%)`

  const termsSource = quote ? (text(record.terms) ?? (draft ? text(issuer.default_quote_terms) : null)) : (text(record.payment_terms) ?? (draft ? text(issuer.default_payment_terms) : null))
  const closingText = text(quote ? issuer.quote_closing_text : issuer.invoice_closing_text)

  const bankFields: Array<[string, string]> = [
    ['Bank', 'bank_name'], ['Account Name', 'bank_account_name'], ['Account Number', 'bank_account_number'],
    ['Branch Code', 'bank_branch_code'], ['Account Type', 'bank_account_type'],
  ]

  return {

    title: info.title,
    draft,
    number,

    project,
    fromHeading: quote ? 'Prepared by' : 'From',
    from: { name: text(issuer.legal_name), lines: addressLines(issuer), vatNumber: text(issuer.vat_number) },
    currency,
    lines: [...input.lines]
      .sort((a, b) => Number(a.position ?? 0) - Number(b.position ?? 0))
      .map((line) => ({
        title: text(line.title) ?? '',
        description: text(line.description),
        quantity: formatQuantity(line.quantity),
        unitPrice: formatAmount(line.unit_price),
        amount: formatAmount(line.line_amount),
      })),
    totals: { subtotal: formatAmount(record.subtotal), vatLabel, vat: formatAmount(record.tax_amount), total: formatAmount(record.total_amount) },

  lines: DocumentLine[]

  settings: CompanySettings | null

/** A quote or invoice with its lines, its live client and the company details; null when it does not exist. */
export async function getDocument(kind: DocumentKind, id: string): Promise<DocumentBundle | null> {
  if (!isDocumentKind(kind) || !isUuid(id)) return null
  const { organization, db } = await documentContext()
  const info = DOCUMENTS[kind]
  const found = await db.from(info.table).select('*').eq('id', id).eq('organization_id', organization.id).maybeSingle()
  if (found.error) throw found.error
  if (!found.data) return null
  const record = found.data as Record<string, any>

  const [lines, client, settings] = await Promise.all([
    db.from(info.lines).select('*').eq(info.parentColumn, id).eq('organization_id', organization.id).order('position').order('created_at'),
    record.client_id

      : Promise.resolve({ data: null, error: null }),
    db.from('organization_settings').select('*').eq('organization_id', organization.id).maybeSingle(),
  ])
  for (const result of [lines, client, settings]) {
    if (result.error) throw result.error
  }
  return {
    record,
    lines: (lines.data ?? []) as DocumentLine[],
    client: (client.data as Record<string, any> | null) ?? null,
    settings: (settings.data as CompanySettings | null) ?? null,
  }

'use server'

import { isUuid } from '@/lib/utils'
import { documentErrorMessage } from '../errors'
import { readLineFields } from '../fields'
import { revalidateDocumentPages } from '../revalidate'
import { documentContext } from '../server-context'

import { DOCUMENTS, isDocumentKind } from '../vocabulary'

const NOT_FOUND = 'That document was not found.'

function lineError(error: { message?: string; code?: string } | null): string {
  const mapped = documentErrorMessage(error?.message)
  if (mapped) return mapped
  if (error?.code === '23503') return 'That price list item or document no longer exists.'
  if (error?.code === '42501') return NOT_FOUND
  return 'The line could not be saved. Check the quantity and the price.'
}

export async function addLineAction(kind: string, documentId: string, _previous: ActionState, form: FormData): Promise<ActionState> {
  if (!isDocumentKind(kind) || !isUuid(documentId)) return { error: NOT_FOUND }
  const fields = readLineFields(form)
  if ('error' in fields) return { error: fields.error }
  const { organization, db } = await documentContext()
  const info = DOCUMENTS[kind]
  const last = await db
    .from(info.lines)
    .select('position')
    .eq(info.parentColumn, documentId)
    .eq('organization_id', organization.id)
    .order('position', { ascending: false })
    .limit(1)
  if (last.error) return { error: lineError(last.error) }
  const position = Number(last.data?.[0]?.position ?? 0) + 1
  const saved = await db
    .from(info.lines)
    .insert({ organization_id: organization.id, [info.parentColumn]: documentId, position, ...fields })
    .select('id')
    .single()
  if (saved.error || !saved.data) return { error: lineError(saved.error) }
  revalidateDocumentPages()
  return { success: 'Line added.' }
}

export async function updateLineAction(kind: string, lineId: string, _previous: ActionState, form: FormData): Promise<ActionState> {
  if (!isDocumentKind(kind) || !isUuid(lineId)) return { error: NOT_FOUND }
  const fields = readLineFields(form)
  if ('error' in fields) return { error: fields.error }
  const { organization, db } = await documentContext()
  const saved = await db
    .from(DOCUMENTS[kind].lines)
    .update(fields)
    .eq('id', lineId)
    .eq('organization_id', organization.id)
    .select('id')
    .maybeSingle()
  if (saved.error) return { error: lineError(saved.error) }
  if (!saved.data) return { error: 'That line no longer exists.' }
  revalidateDocumentPages()
  return { success: 'Line saved.' }
}

export async function removeLineAction(kind: string, lineId: string, _previous: ActionState, _form: FormData): Promise<ActionState> {
  if (!isDocumentKind(kind) || !isUuid(lineId)) return { error: NOT_FOUND }
  const { organization, db } = await documentContext()
  const removed = await db
    .from(DOCUMENTS[kind].lines)
    .delete()
    .eq('id', lineId)
    .eq('organization_id', organization.id)
    .select('id')

  if (!removed.data?.length) return { error: 'That line no longer exists.' }
  revalidateDocumentPages()
  return { success: 'Line removed.' }
}

/** Swaps a line with its neighbour and renumbers the document's lines 1..n. */
export async function moveLineAction(
  kind: string,
  documentId: string,
  lineId: string,
  direction: 'up' | 'down',
  _previous: ActionState,
  _form: FormData,
): Promise<ActionState> {
  if (!isDocumentKind(kind) || !isUuid(documentId) || !isUuid(lineId)) return { error: NOT_FOUND }
  const { organization, db } = await documentContext()
  const info = DOCUMENTS[kind]
  const read = await db
    .from(info.lines)
    .select('id,position')
    .eq(info.parentColumn, documentId)
    .eq('organization_id', organization.id)
    .order('position')
    .order('created_at')
  if (read.error) return { error: lineError(read.error) }
  const ordered: Array<{ id: string; position: number }> = [...(read.data ?? [])]
  const index = ordered.findIndex((line) => line.id === lineId)
  if (index < 0) return { error: 'That line no longer exists.' }
  const target = direction === 'up' ? index - 1 : index + 1
  if (target < 0 || target >= ordered.length) return { success: 'Already there.' }
  ;[ordered[index], ordered[target]] = [ordered[target], ordered[index]]
  for (const [position, line] of ordered.entries()) {
    if (Number(line.position) === position + 1) continue
    const moved = await db
      .from(info.lines)
      .update({ position: position + 1 })
      .eq('id', line.id)
      .eq('organization_id', organization.id)
      .select('id')
      .maybeSingle()
    if (moved.error || !moved.data) return { error: lineError(moved.error) }
  }
  revalidateDocumentPages()
  return { success: 'Moved.' }
}

            <LineRow key={line.id} kind={kind} documentId={documentId} line={line} index={index} count={lines.length} locked={locked} money={money} />
          ))}
        </ul>
      ) : (
        <p className="px-5 py-6 text-sm text-[var(--briefing-muted)]">No lines yet.{locked ? '' : ' Add the first one below.'}</p>
      )}
      <dl className="ml-auto grid max-w-xs grid-cols-[1fr_auto] gap-x-6 gap-y-1 border-t border-border px-5 py-4 text-sm">
        <dt className="text-[var(--briefing-muted)]">Subtotal</dt>
        <dd className="text-right">{money(totals.subtotal)}</dd>
        <dt className="text-[var(--briefing-muted)]">VAT ({Number(totals.vatRate)}%)</dt>
        <dd className="text-right">{money(totals.tax)}</dd>
        <dt className="font-semibold text-foreground">Total</dt>
        <dd className="text-right font-semibold text-foreground">{money(totals.total)}</dd>
      </dl>
      {locked ? null : <AddLineForm kind={kind} documentId={documentId} priceItems={priceItems} />}
    </WorkspaceSection>
  )
}

function LineRow({

}: {
  kind: DocumentKind
  documentId: string
  line: DocumentLine
  index: number
  count: number

  const [editing, setEditing] = useState(false)

        <div className="flex flex-wrap gap-2">
          <button type="button" onClick={() => setEditing(true)} aria-label={`Edit line: ${line.title}`} className="border border-border px-3 py-1.5 text-xs font-semibold text-foreground">
            Edit
          </button>
          {index > 0 ? <ActionButton action={moveLineAction.bind(null, kind, documentId, line.id, 'up')} label="Up" ariaLabel={`Up: ${line.title}`} /> : null}
          {index < count - 1 ? <ActionButton action={moveLineAction.bind(null, kind, documentId, line.id, 'down')} label="Down" ariaLabel={`Down: ${line.title}`} /> : null}
          <ActionButton action={removeLineAction.bind(null, kind, line.id)} label="Remove" ariaLabel={`Remove: ${line.title}`} confirmText="Remove this line?" tone="danger" />

  )

function EditLineForm({ kind, line, onDone }: { kind: DocumentKind; line: DocumentLine; onDone: () => void }) {

const EMPTY = { title: '', description: '', quantity: '1', unitPrice: '', vatCode: 'standard', priceListItemId: '' }

function AddLineForm({ kind, documentId, priceItems }: { kind: DocumentKind; documentId: string; priceItems: PriceItem[] }) {
  const [state, run, pending] = useActionState(addLineAction.bind(null, kind, documentId), undefined)
  const [, startTransition] = useTransition()
  const [fields, setFields] = useState(EMPTY)
  const set = (key: keyof typeof EMPTY, next: string) => setFields((current) => ({ ...current, [key]: next }))

  // A saved line starts a fresh form; a failed one keeps what was typed.
  useEffect(() => {
    if (state?.success) setFields(EMPTY)
  }, [state])

  function pick(id: string) {
    const item = priceItems.find((candidate) => candidate.id === id)
    if (!item) {
      set('priceListItemId', '')
      return
    }
    setFields((current) => ({
      ...current,
      priceListItemId: item.id,
      title: item.title,
      description: item.description ?? '',
      unitPrice: String(item.unit_price),
      vatCode: item.vat_code,
    }))
  }

  return (
    <form
      onSubmit={(event) => {
        event.preventDefault()
        const data = new FormData()
        for (const [key, value] of Object.entries(fields)) data.set(key, value)
        startTransition(() => run(data))
      }}
      className="grid gap-3 border-t border-border p-5 md:grid-cols-[2fr_1fr_1fr_1fr]"
    >
      <label className="md:col-span-4">
        <span className="sr-only">Fill from the price list</span>
        <select aria-label="Fill from the price list" value={fields.priceListItemId} onChange={(event) => pick(event.target.value)} className={field}>
          <option value="">One-off line (type it below)</option>
          {priceItems.map((item) => <option key={item.id} value={item.id}>{item.title}</option>)}
        </select>
      </label>
      <input aria-label="Title" placeholder="Title" required value={fields.title} onChange={(event) => set('title', event.target.value)} className={field} />
      <input aria-label="Quantity" placeholder="Quantity" required inputMode="decimal" value={fields.quantity} onChange={(event) => set('quantity', event.target.value)} className={field} />
      <input aria-label="Unit price" placeholder="Unit price" required inputMode="decimal" value={fields.unitPrice} onChange={(event) => set('unitPrice', event.target.value)} className={field} />
      <VatSelect value={fields.vatCode} onChange={(next) => set('vatCode', next)} />
      <textarea aria-label="Description" placeholder="Description (optional)" rows={2} value={fields.description} onChange={(event) => set('description', event.target.value)} className="w-full rounded-none border border-border bg-background px-3 py-2 text-sm md:col-span-4" />
      {state?.error ? <p role="alert" className="text-sm text-destructive md:col-span-4">{state.error}</p> : null}
      {state?.success ? <p role="status" className="text-sm text-success md:col-span-4">{state.success}</p> : null}
      <div className="md:col-span-4">
        <button type="submit" disabled={pending} className="bg-brand px-4 py-2 text-sm font-semibold text-white disabled:opacity-60">{pending ? 'Adding…' : 'Add line'}</button>
      </div>
    </form>
  )
}
